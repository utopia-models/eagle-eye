# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
(Security tab, "Report a vulnerability") on this repository. We aim to acknowledge within 3 business days.

## Scope

Eagle Eye is a static page that reads a JSON feed you provide. No credentials or real data ship in this repository;
if you find either, report it the same way so it can be removed and rotated.

## Supported versions

The latest tagged release.
