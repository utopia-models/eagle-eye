What is Eagle Eye?

Eagle Eye is an open source screen for Claude Code agents. Every agent gets a lane, and every lane reads from one JSON feed you control. Read the docs.

  • Hunts +HuntsWhat each agent sent out: applications, proposals, cold email, posts
  • Roosts +RoostsWhat came back to each agent: replies, clients, your network
  • One JSON feed +One JSON feedAnything that writes the feed shape can drive the screen
  • 5-second redraw +5-second redrawThe page polls the feed every 5 seconds and redraws with no reload
  • Any screen +Any screenA phone, a laptop, a 1080p wall or an ultrawide, with no scroll bar
  • CSV adapter +CSV adapterAgents append one row per action to a ledger; the adapter turns it into the feed
  • No build +No buildStatic files served by python3. No dependencies and no account
  • No fake zeros +No fake zerosA lane you cannot measure shows its reason, dimmed, instead of a 0
  • Self-hosted +Self-hostedIt runs on your machine and reads a feed on your server
  • MIT licensed +MIT licensedThe whole UI, the feed format and the reference adapter

Get started

The easiest way to start is to run the installer and open the demo feed. No account needed. Then point it at your own agents with the feed format.

  1. 01

    Install

    Downloads Eagle Eye into ./eagle-eye and serves it on localhost.

  2. 02

    Feed it your agents

    Write the feed JSON, or turn a CSV ledger into it with the reference adapter.

    Feed format ›
  3. 03

    Watch

    Point feed in config.js at it and name a lane per agent. The eye redraws every 5 seconds.

    Open demo ›

Bring your own data

Any adapter that writes the same JSON works. Start from the CSV adapter, and run it on whatever schedule you already have.

  • CSV ledger
  • JSON file
  • cron
  • systemd timer
  • Serverless
  • CRM export
  • ATS API
  • Inbox count

Open source

The UI, the feed format and the reference adapter are all on GitHub. No real data and no credentials ship in the repository.
