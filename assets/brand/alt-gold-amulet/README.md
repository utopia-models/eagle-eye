# Gold Amulet (alternate mark)

Approved alternate mark that can be used for merch, splash or social. It is not the app icon (the app icon is Horus, `assets/icon/`).

The Eye of Horus struck in ink into a plate of the live.utopiamodels.ai gold sand, like the wedjat amulet Egyptians wore for protection. Concept B of the A-F round (`assets/icon/review/concepts-a-f.png`).

| File | What |
|---|---|
| `gold-amulet-1024.png` | the master, 1024, opaque |
| `homescreen-48dp-1x.png`, `homescreen-48dp-device.png` | at 48 dp on a mock Pixel home screen beside real app icons |
| `favicon.svg`, `favicon-1024.png` | the flat mark: ink wedjat on a gold tile (vector and raster) |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon.ico` | small sizes; 16 px is drawn on the pixel grid |

Regenerate any size: `cd assets/icon/src && python build.py <out-dir> wadjet-gold` (and `python svgmask.py wadjet-gold <out.svg>`).
