# Follow-up cadence: {{client_name}}

Rules: one message per person per day, no duplicate of a sent message, no signature block, answer the last question first, keep every promise made.

| When | Message |
|---|---|
| Day 0, offer sent | The offer, one line pointing to it. |
| Day 1, no reply | One line: "Any question on the offer?" |
| Day 3 | The result so far, in one sentence, and the one thing we need from you. |
| Day 7 | A short update with what shipped; ask for feedback. |
| Day 14, milestone due | Delivery note with how each acceptance line is met. |
