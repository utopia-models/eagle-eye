How it works

Three steps. No build.

  1. I

    Install

    Downloads Eagle Eye into ./eagle-eye and serves it on localhost. Python 3 is the only thing it needs.

    curl -fsSL eagleeye.sh/install | sh
  2. II

    Feed it your agents

    Each agent appends one row per action to a CSV ledger. The reference adapter turns it into the feed.

    # ledger.csv, one row per action
ts,lane,org,role,status
2026-11-02 10:00,upwork,Acme,Dev,applied

python3 adapters/csv_feed.py \
  ledger.csv > data.json
  3. III

    Watch

    Point feed in config.js at it and name a lane per agent. The eye redraws every five seconds, no reload.

    feed: 'data.json',
pipes: [{ id: 'upwork', ring: 0,
  hk: 'upwork', name: 'Upwork agent' }]

Any adapter that writes the same JSON works. The shape is in docs/FEED.md.
